# Backend API Reference

The independent backend exposes REST endpoints and Server-Sent Events (SSE) streaming routes. All requests and responses are strictly validated via Zod schemas.

---

## 1. System Health

### `GET /api/health`
Performs a health check verifying server uptime, active sessions, and AI provider connectivity.

**Response `200 OK` (Healthy):**
```json
{
  "status": "ok",
  "service": "ai-assistant-plugin-backend",
  "timestamp": "2026-10-28T04:41:42.795Z",
  "uptimeSeconds": 1420,
  "provider": {
    "name": "gemini",
    "available": true,
    "model": "gemini-3.5-flash",
    "message": "Gemini provider is healthy and responsive."
  },
  "sessions": {
    "activeSessions": 2,
    "ttlMs": 7200000,
    "maxContextMessages": 20
  }
}
```

**Response `503 Service Unavailable` (Degraded):**
```json
{
  "status": "degraded",
  "provider": {
    "name": "gemini",
    "available": false,
    "message": "GEMINI_API_KEY is not configured on the server."
  }
}
```

## 2. Public Assistant Configuration

### `GET /api/config/:assistantId`
Retrieves public customization settings for the specified assistant persona. Sensitive server-side properties (e.g. system instructions) are excluded.

**Path Parameters:**
- `assistantId` (string, required): Preset identifier (e.g. `default`, `researcher`, `support`, `coder`).

**Response `200 OK`:**
```json
{
  "assistant": {
    "assistantId": "default",
    "name": "AI Assistant",
    "description": "General-purpose intelligent assistant",
    "theme": "auto",
    "primaryColor": "#4f46e5",
    "position": "bottom-right",
    "greeting": "Hello! How can I help you today?",
    "suggestedPrompts": [
      "Summarize this document",
      "Extract key action items",
      "Explain this in simple terms"
    ],
    "features": {
      "streaming": true,
      "summarization": true,
      "copyResponse": true,
      "clearHistory": true,
      "markdown": true,
      "structuredOutput": true
    }
  }
}
```

## 3. Conversational Chat API

### `POST /api/chat`
Standard non-streaming conversational endpoint. Preserves multi-turn conversation context.

**Request Body (`application/json`):**
```json
{
  "assistantId": "default",
  "message": "What is the capital of France?",
  "conversationId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "parameters": {
    "temperature": 0.7,
    "maxTokens": 2048
  }
}
```

**Response `200 OK`:**
```json
{
  "conversationId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "text": "The capital of France is Paris.",
  "model": "gemini-3.5-flash",
  "finishReason": "STOP",
  "timestamp": "2026-10-28T04:40:03.255Z"
}
```

---

### `POST /api/chat/stream`
Server-Sent Events (SSE) streaming endpoint. Delivers tokens progressively as generated by the provider.

**Request Body (`application/json`):** Same schema as `POST /api/chat`.

**Response Headers:**
```http
Content-Type: text/event-stream
Cache-Control: no-cache, no-transform
Connection: keep-alive
X-Accel-Buffering: no
```

**SSE Event Sequence:**
1. Handshake Event:
   ```
   data: {"type":"start","conversationId":"3fa85f64-5717-4562-b3fc-2c963f66afa6"}
   ```
2. Token Chunk Events:
   ```
   data: {"type":"chunk","delta":"The "}
   data: {"type":"chunk","delta":"capital "}
   data: {"type":"chunk","delta":"is Paris."}
   ```
3. Completion Event:
   ```
   data: {"type":"done","conversationId":"3fa85f64-5717-4562-b3fc-2c963f66afa6","text":"The capital is Paris.","model":"gemini-3.5-flash"}
   ```

## 4. Text Summarization API

### `POST /api/summarize`
Synthesizes provided text according to the selected output style.

**Request Body (`application/json`):**
```json
{
  "text": "Antigravity is an AI pair programming framework...",
  "style": "concise",
  "focus": "security architecture",
  "stream": false
}
```

**Supported Styles:**
- `concise`: Single paragraph (under 120 words).
- `detailed`: Comprehensive multi-section analysis.
- `bullet_points`: Distinct core points.
- `key_takeaways`: Top 3-5 high-impact conclusions.
- `action_items`: Concrete tasks, owners, and deliverables.
- `structured_json`: Valid machine-readable JSON.

**Response `200 OK` (`style: concise`):**
```json
{
  "summary": "Antigravity provides automated coding tools with strict security boundaries.",
  "structured": null,
  "style": "concise",
  "model": "gemini-3.5-flash",
  "timestamp": "2026-10-28T04:40:03.526Z"
}
```

**Response `200 OK` (`style: structured_json`):**
```json
{
  "summary": "...",
  "structured": {
    "summary": "High-level overview",
    "keyPoints": ["point 1", "point 2"],
    "actionItems": ["action 1"],
    "sentiment": "objective"
  },
  "style": "structured_json",
  "model": "gemini-3.5-flash"
}
```

## 5. Session Management API

### `POST /api/sessions/clear`
Clears the active conversation messages from the server's in-memory session store.

**Request Body:**
```json
{
  "conversationId": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

**Response `200 OK`:**
```json
{
  "success": true,
  "cleared": true,
  "conversationId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "message": "Conversation history cleared successfully"
}
```

## 6. Connectors API

### `GET /api/connectors`
Returns public metadata and supported actions for registered application connectors.

### `POST /api/connectors/execute`
Executes an external action with server-side authorization check.

**Request Body:**
```json
{
  "connectorId": "mock-knowledge",
  "action": "searchKnowledge",
  "parameters": {
    "query": "widget"
  },
  "authToken": "optional-token-if-protected"
}
```

## 7. Error Codes & HTTP Statuses

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `VALIDATION_ERROR` | Request payload failed schema validation (e.g. empty message). |
| `400` | `MALFORMED_JSON` | Request body is not valid JSON. |
| `401` | `UNAUTHORIZED` | Connector action requires a valid authorization token. |
| `403` | `CORS_FORBIDDEN` | Request origin is not permitted by CORS policy. |
| `429` | `RATE_LIMIT_EXCEEDED` | Client exceeded the rate limit threshold (e.g. 60 req/min). |
| `499` | `CLIENT_CLOSED_REQUEST` | Client aborted connection before completion. |
| `504` | `REQUEST_TIMEOUT` | Upstream AI provider failed to respond within timeout window. |
| `500` | `INTERNAL_SERVER_ERROR` | Safe generic error masking server internals. |
